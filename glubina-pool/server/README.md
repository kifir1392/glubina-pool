# Серверные файлы сайта

`send-form.php` — обработчик формы заявки. Работает на хостинге (PHP), в статический
экспорт Next.js не входит.

- Боевое расположение: корень сайта на хостинге (`/www/glubina-pool.ru/send-form.php`).
- Эта копия хранится в репозитории как резервная: при переустановке хостинга загрузить
  файл обратно в корень сайта по FTP.
- Форма на сайте отправляет POST на `/send-form.php` (см. `app/page.tsx`).
